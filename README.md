## 🚀 Features

- **Immersive Design**: Dynamic scroll animations, smooth transitions, and a premium dark mode aesthetic tailored for operational tools.
- **Responsive Layout**: Optimized for all devices, from large command center displays to mobile screens.
- **High-Performance**: Built with Next.js App Router for optimal loading speeds, SEO, and developer experience.
- **Custom Branding**: Fully customized favicon, logos, and UI components matching the AEGIS visual identity.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (React)
- **Styling**: Tailwind CSS + Custom CSS
- **Language**: TypeScript
- **Package Manager**: Bun

## ⚙️ Getting Started

First, install the dependencies:

```bash
bun install
```

Then, run the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `/src/app`: Contains the main application pages, layout, and global styles.
- `/src/components`: Reusable UI components (Hero Video, Feature Cards, Scroll Animations).
- `/public`: Static assets including favicons, site icons, and optimized media.
- `/Frames`: Raw design files, prototypes, and additional reference media.
